المرحلة ٢ — نسبة الجماهير + تحدي الأندية (Firebase Realtime Database عبر REST، من غير SDK)
- make_rules.py يولّد rules.json (L = منتصف ليل ١٧ نوفمبر ٢٠٢٦ بتوقيت الإمارات). القواعد: سجل واحد لكل لاعب/يوم/وضع، عدّادات +1 بس، نقاط النادي = 7 - المحاولة، اليوم الحالي أو أمس بس.
- البنية: p/{day}/{mode}/{uid}={d,g,c} (مقفول)، s/{day}/{mode}={n,w,g1..g6} (مقروء)، c/{day}/{mode}/{club}={n,t} (مقروء).
- الإعداد في mano/index.html: const FB={key:'',db:''}. فاضي = الميزة مخفية واللعبة تشتغل عادي.
- صفحة التجهيز لإبراهيم: /setup/firebase.html
- اختبار: محاكي Firebase (firebase-tools) — اجتازت كل الحالات: تكرار، يوم مستقبلي، غش نقاط، نادي غلط، ٥ طلبات متزامنة.
