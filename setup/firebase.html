🔥 تجهيز Firebase — المرحلة ٢

٥ دقايق بس، من التلفون أو الكمبيوتر. الخطة المجانية (Spark)، ما يبالها بطاقة.

  1. افتح console.firebase.google.com ← Create a project ← الاسم el3azy ← طفّي Google Analytics ← Create.
  2. من القائمة: Build ← Authentication ← Get started ← تبويب Sign-in method ← Anonymous ← Enable ← Save.
  3. Build ← Realtime Database ← Create Database ← الموقع Belgium (europe-west1) ← Start in locked mode ← Enable.
  4. في نفس الصفحة افتح تبويب Rules، امسح اللي فيه، والصق القواعد (اضغط الزر تحت) ← Publish.
  5. ⚙️ Project settings ← General ← تحت Your apps اضغط أيقونة الويب </> ← الاسم mano ← Register app.
  6. بيطلع لك firebaseConfig. انسخ لي سطرين بس وارسلهم في المحادثة: apiKey و databaseURL.
    لو ما طلع databaseURL، تلقاه فوق صفحة Realtime Database (يخلص بـ firebasedatabase.app).

هذي المفاتيح عامة أصلاً وتنحط في صفحة اللعبة، والحماية في القواعد. ✅
